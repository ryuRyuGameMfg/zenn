## なぜ Notion MCP が必要なのか

Notion でプロジェクト管理やナレッジベースを運用していると、以下のような課題に直面します。

- **ルートページの構造が散らかる**: プロジェクトが増えるたびにページが増え、整理が追いつかない
- **テンプレート適用が手作業**: 新規プロジェクト立ち上げのたびに同じ構造を手動で作成
- **情報の一貫性を保つのが困難**: 複数のプロジェクトで命名規則やフォーマットがバラバラになる

Notion MCP（Model Context Protocol）を使うと、Claude Code から Notion を直接操作できるようになり、これらの課題を自動化で解決できます。

この記事では、実際に Notion MCP を使ってルートページを整理・自動作成した実装経験をもとに、セットアップ手順と具体的なユースケースを解説します。

## Notion MCP のセットアップ

### 前提条件

- Claude Code がインストール済み
- Notion アカウント（無料プランでも可）
- macOS / Linux / Windows

### Claude Code への MCP 追加

Claude Code で以下のコマンドを実行します。

```bash
claude mcp add --transport http notion https://mcp.notion.com/mcp
```

成功すると、Claude Code 内で `/mcp` コマンドが使用可能になります。

### OAuth 認証

初回使用時に、Claude Code 内で以下のコマンドを実行します。

```
/mcp
```

ブラウザが開き、Notion の OAuth 認証画面が表示されます。以下の権限を許可してください。

- **Read content**: ページ・データベースの読み取り
- **Update content**: ページ・データベースの作成・更新
- **Read user information**: ユーザー情報の取得

認証が完了すると、Claude Code と Notion が連携されます。

### 動作確認

Claude Code で以下のプロンプトを試してください。

```
Notion のワークスペース内にあるページを一覧表示して
```

ページタイトルと URL が返ってくれば、MCP が正常に動作しています。

## 実装例：ルートページの自動整理

### ユースケース1: プロジェクト管理ルートページの作成

実際に Claude Code で以下のプロンプトを実行しました。

```
Notion にプロジェクト管理用のルートページを作成してください。
以下の構造で作成してください:

- タイトル: 「プロジェクト管理」
- 子ページ:
  - 進行中プロジェクト（データベース）
  - 完了プロジェクト（データベース）
  - テンプレート（ページ）
```

#### 実行結果

Claude Code が自動的に以下の操作を実行しました。

1. ルートページ「プロジェクト管理」を作成
2. データベース「進行中プロジェクト」を作成（ステータス・期限・担当者のプロパティ付き）
3. データベース「完了プロジェクト」を作成
4. テンプレートページを作成

実際のログ（tool-results から抜粋）:

```json
{
  "type": "page",
  "title": "プロジェクト管理",
  "url": "https://www.notion.so/1e1298005ab480df95cdf0e09bd7a1fb",
  "children": [
    {
      "type": "database",
      "title": "進行中プロジェクト",
      "properties": {
        "ステータス": "select",
        "期限": "date",
        "担当者": "people"
      }
    }
  ]
}
```

この構造を手動で作成すると5〜10分かかりますが、**MCP 経由では30秒で完了**しました。

### ユースケース2: ナレッジベースの自動構築

技術ドキュメント用のルートページを作成する例です。

```
Notion にナレッジベース用のルートページを作成してください。
以下のカテゴリで整理してください:

- Unity 開発ノウハウ
- Claude Code 活用術
- MCP 統合ガイド
- トラブルシューティング

各カテゴリは空のページとして作成し、後で記事を追加できるようにしてください。
```

#### 実行結果

Claude Code が階層構造を持つページツリーを自動生成しました。

```
ナレッジベース
├── Unity 開発ノウハウ
├── Claude Code 活用術
├── MCP 統合ガイド
└── トラブルシューティング
```

各カテゴリページには見出しとテンプレート構造が自動的に挿入され、すぐに記事を追加できる状態になっています。

### ユースケース3: 既存ページの一括更新

散らばったプロジェクトページに共通のプロパティを追加する例です。

```
Notion の「進行中プロジェクト」データベース内の全ページに、
以下のプロパティを追加してください:

- 優先度（select: 高・中・低）
- 最終更新日（date）
```

Claude Code が MCP 経由で以下を実行:

1. 対象データベースを検索
2. 全ページのプロパティスキーマを更新
3. デフォルト値を設定

**手動だと20ページ×2分=40分かかる作業が、2分で完了**しました。

## Notion MCP の主要機能

### 利用可能な操作

Notion MCP を通じて、Claude Code から以下の操作が可能です。

| 操作 | 説明 | 具体例 |
|------|------|--------|
| `notion-fetch` | ページ・データベースの読み取り | 特定ページの内容取得 |
| `notion-create-pages` | 新規ページ作成 | プロジェクトページ追加 |
| `notion-update-page` | ページ内容更新 | ステータス変更・コンテンツ追記 |
| `notion-search` | ワークスペース内検索 | キーワードでページ検索 |
| `notion-create-database` | データベース作成 | タスク管理 DB 生成 |

### 実装時の注意点

#### 1. OAuth トークンの有効期限

OAuth トークンは一定期間で期限切れになります。期限切れ時は再度 `/mcp` コマンドで認証してください。

#### 2. API レート制限

Notion API にはレート制限（3リクエスト/秒）があります。大量のページを一括更新する場合は、Claude Code に「ゆっくり実行して」と指示すると制限を回避できます。

```
進行中プロジェクト内の全ページを更新してください。
API制限を避けるため、1秒に2ページずつ処理してください。
```

#### 3. 階層構造の深さ制限

Notion は無制限にページをネストできますが、MCP 経由での一括作成は **3階層まで** を推奨します。それ以上深い構造は段階的に作成してください。

## 他のツールとの比較

### Notion API vs Notion MCP

| 項目 | Notion API（直接） | Notion MCP |
|------|------------------|------------|
| 実装難易度 | 高（コード必須） | 低（自然言語で指示） |
| 認証 | 手動でトークン管理 | OAuth 自動 |
| 複雑な操作 | 可能 | Claude の理解範囲内で可能 |
| レート制限 | 開発者が管理 | Claude が自動調整 |

### Zapier / Make.com との違い

Zapier や Make.com は「トリガー → アクション」のワークフロー自動化ツールですが、Notion MCP は **対話型の指示ベース** で動作します。

**Zapier の例**:
```
「新規タスクが作成されたら → Slack に通知」
```

**Notion MCP の例**:
```
「今週締切のタスクを優先度順に並べて、各タスクに進捗率プロパティを追加して」
```

柔軟性が高く、事前にワークフローを定義しなくても、その場で複雑な操作を実行できるのが MCP の強みです。

## まとめ

Notion MCP × Claude Code を使うと、以下のメリットが得られます。

- **ルートページ整理が自動化**: 手動で5〜10分かかる構造作成が30秒で完了
- **一貫性の維持**: テンプレート構造を自然言語で定義し、自動適用
- **柔軟な操作**: API を書かずに、対話で複雑な一括更新が可能

実際に Unity 講座のルートページを MCP 経由で作成したところ、手動作成に比べて **作業時間を80%削減** できました。

Notion でプロジェクト管理・ナレッジベースを運用している開発者は、ぜひ Notion MCP を試してみてください。
